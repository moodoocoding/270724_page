# AI 원데이 클래스 수업 설계 보조도구

교사가 자신의 수업 문제를 구체화하고, 생성형 AI와 함께 해결 방법을 탐색한 뒤, 실제 수업에서 사용할 콘텐츠를 제작·검토할 수 있도록 돕는 웹 기반 보조도구입니다.

이 프로젝트는 `docs` 디렉터리의 **「2026. 연수 표준안_원클강사(AI 수업)」** PPTX 및 PDF를 기본 기획 문서로 사용합니다.

## 프로젝트 배경

원데이 클래스의 핵심은 단순히 AI 도구의 사용법을 익히는 것이 아닙니다. 교사가 학생의 행동을 성급하게 판단하지 않고 배움이 막힌 지점을 찾은 뒤, 교사가 바꿀 수 있는 수업 조건을 정의하고 실행 가능한 결과물까지 완성하는 데 목적이 있습니다.

이 웹페이지는 연수 참여자가 다음 과정을 놓치지 않고 수행하도록 안내합니다.

1. 학생의 배움을 막는 수업 문제를 구체화합니다.
2. AI의 도움을 받아 여러 수업 방법을 탐색합니다.
3. 선택한 방법을 실제 수업 콘텐츠로 제작합니다.
4. 동료 검토와 수정을 거쳐 실행 가능한 결과물로 완성합니다.

> 문제 먼저, AI는 그다음.

AI는 여러 아이디어와 초안을 빠르게 제안하고, 교사는 정확성·적합성·실행 가능성을 검토하여 실제 사용할 방법을 결정합니다.

## 대상 사용자

- AI를 수업 설계와 자료 제작에 활용하려는 교사
- AI 원데이 클래스에 참여하는 연수생
- 참여자의 실습과 결과물 제작을 지원하는 강사 및 운영자

## 사용자 여정

### 1. 수업 문제 정의

학생의 행동에 대한 처음 판단과 추가 정보를 구분하고, 사실과 해석을 검토합니다. 학생 개인의 태도나 성향을 설명하는 데서 멈추지 않고 교사가 수업에서 바꿀 수 있는 조건을 찾습니다.

주요 입력:

- 기억에 남는 수업 장면
- 학생이 실제로 한 행동과 말
- 처음 내린 판단
- 판단을 바꿀 수 있는 추가 정보
- 배움이 막힌 지점
- 수업에서 시도할 변화

주요 산출물:

- **수업 문제 정의서**

기본 문장 틀:

```text
처음에는 ________이라고 판단했다.
그러나 ________을 확인한 뒤,
________이 배움을 막았을 가능성이 있다고 보았다.
따라서 수업에서 ________을 해 볼 필요가 있다.
```

### 2. 수업 방법 탐색

수업 문제 정의서를 바탕으로 AI에 전달할 요청을 구체화하고, 서로 다른 해결 방법을 탐색합니다. 필요하면 조건을 바꾸어 다시 요청하고, 우리 반에 적용할 방법 하나를 선택합니다.

주요 기능:

- 학년, 교과, 수업 상황, 학생의 어려움 입력
- 원하는 활동과 결과 형식 설정
- AI 요청문 또는 완성형 프롬프트 생성
- 여러 수업 방법 비교
- 선택 기준에 따른 후보 평가

선택 기준:

- 발견한 배움의 문제에 직접 도움이 되는가?
- 학생이 실제로 수행할 수 있는가?
- 시간, 언어 수준, 참여 방식이 현실적인가?
- 기존 수업 흐름에 넣을 수 있는가?

주요 산출물:

- **수업 콘텐츠 개발 계획**

기본 문장 틀:

```text
나는 수업의 ________에서
학생이 ________하도록
________을 만들겠다.
```

### 3. 수업 콘텐츠 제작

선택한 수업 방법을 학생이 실제로 사용할 수 있는 콘텐츠로 제작합니다. 이미지, 활동지, 카드, 슬라이드, 퀴즈, 게임, 단일 HTML 웹앱 등 다양한 형태를 지원할 수 있습니다.

제작 조건:

- 만들 콘텐츠
- 사용할 AI 도구
- 교실의 기기 및 사용 환경
- 필요한 핵심 기능
- 결과물 형식
- 활용할 수업 자료

주요 산출물:

- 시각 콘텐츠
- 학생 활동 자료
- 수업용 HTML 프로그램 또는 공유 링크

### 4. 검토·수정·공유

갤러리 워크 방식으로 동료가 결과물을 직접 사용해 보고 구체적인 의견을 남깁니다. 교사는 중요한 의견을 선택해 최종 결과물에 반영합니다.

검토 관점:

- **배움:** 처음 정의한 학생의 어려움에 도움이 되는가?
- **활동:** 사용 방법과 학생의 행동이 구체적인가?
- **실행:** 실제 수업의 시간·기기·환경에서 작동하는가?
- **정확성과 안전:** 내용, 수준, 개인정보, 편향이 적절한가?

수정 우선순위:

1. 잘못된 내용
2. 작동하지 않는 기능
3. 이해하기 어려운 안내
4. 학생 수준에 맞지 않는 문장이나 문항
5. 지나치게 많은 내용
6. 작은 글자와 버튼 등 사용성 문제
7. 화면 배치와 꾸밈 요소

## 핵심 기능 제안

초기 버전은 다음 기능을 중심으로 개발합니다.

- 단계별 실습을 안내하는 워크플로
- 단계별 입력 내용의 자동 저장
- 수업 문제 정의서 작성 및 수정
- AI 프롬프트 초안 생성
- 수업 방법 후보 기록·비교·선택
- 콘텐츠 제작 조건 정리
- 결과물 파일 또는 링크 등록
- 동료 피드백 작성
- 최종 결과물과 과정 기록 내보내기

## 화면 구성 초안

```text
시작/안내
  └─ 1단계: 수업 문제 정의
       └─ 2단계: 수업 방법 탐색
            └─ 3단계: 콘텐츠 제작
                 └─ 4단계: 검토 및 수정
                      └─ 결과물 요약/공유
```

각 단계에서는 다음 요소를 공통으로 제공합니다.

- 현재 단계와 진행률
- 짧고 명확한 활동 안내
- 예시 보기
- 작성 영역
- 임시 저장 및 다음 단계 이동
- 이전 단계 결과 확인

## 개발 원칙

- **교육 문제 중심:** 특정 AI 기능보다 학생의 배움과 수업 문제를 먼저 다룹니다.
- **교사 주도:** AI의 결과를 정답으로 제시하지 않고 교사가 검토하고 선택하도록 합니다.
- **단계적 안내:** 복잡한 프롬프트 작성보다 짧은 질문과 예시로 사고 과정을 돕습니다.
- **실행 가능성:** 연수 중 만든 결과물을 실제 교실에서 사용할 수 있어야 합니다.
- **안전과 책임:** 개인정보, 저작권, 편향, 사실 오류를 검토할 수 있는 장치를 둡니다.
- **접근성:** 읽기 쉬운 글자, 충분한 대비, 명확한 버튼과 키보드 사용을 고려합니다.

## 데이터베이스

운영 데이터는 Supabase PostgreSQL에 저장합니다. 브라우저가 데이터베이스에 직접 접근하지 않고, 웹서비스의 서버 API가 Supabase와 통신합니다.

저장 대상:

- 클래스와 강사 관리 정보
- 참여자의 학교명과 이름
- 차시별 작성 내용
- 임시 저장 및 제출 상태
- 마지막 수정 시각

초기 스키마는 `supabase/schema.sql`에 있습니다. Supabase 프로젝트의 SQL Editor에서 한 번 실행하면 기본 클래스도 함께 생성됩니다.

서버 환경변수:

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

`SUPABASE_SERVICE_ROLE_KEY`는 브라우저 코드나 공개 저장소에 넣지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## Vercel 배포

이 프로젝트는 표준 Next.js App Router 구조이며 GitHub 저장소를 Vercel에 연결해 배포할 수 있습니다.

Vercel 프로젝트의 Environment Variables에 다음 값을 등록합니다.

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

두 값은 Production, Preview, Development 환경에 필요한 범위만 선택해 등록합니다. `SUPABASE_SERVICE_ROLE_KEY`는 Sensitive 값으로 취급합니다.
